What this is
Everything the website project needs to publish the Netring GPO Compliance page and its downloads. The same files are published in a public GitHub repository, https://github.com/rrvalcourt69-source/netring-gpo-compliance-releases (branch main), in these same folders. The website pulls them from there. That repository is separate from the private product source. It holds only the latest version: one commit that is replaced on every update, so it has no history, and every file has a fixed name with no version in it.

Product facts for the page
- Name: Netring GPO Compliance. Say "formerly GPO Analyzer" once for people who know the old name.
- Company: NetRing Tech Services, LLC. Contact: info@netring.net
- What it does: shows how Group Policy is built across Active Directory domains, scores it against Microsoft security baselines and DISA STIGs, maps it to NIST SP 800-171 and CMMC (control compliance, SPRS score range, POA&M), and tells you what to change.
- It never changes Active Directory. It reads an export made by a collector script. It can write apply and undo PowerShell scripts; they only preview unless run with -Apply, and they link new GPOs disabled.
- Runs on Windows 10, Windows 11 or Windows Server. One program, GPOCompliance.exe, nothing to install. Signed by NetRing Tech Services, LLC.
- Eight PDF reports: executive summary, baseline compliance, control compliance (NIST 800-171), SPRS score and POA&M, remediation plan, GPO inventory and findings, OU and tier review, migration plan.
- Claims to avoid: it does not certify CMMC compliance. Group Policy shows evidence for 18 of the 110 NIST SP 800-171 practices; a person must assess and sign off the rest. Say "an aid for your assessment", never "compliance guaranteed".

Rules for the images and samples
- All data is fictional (Northwind). Do not replace it with a real customer, domain or computer name.
- Keep the screenshots unedited. The folder path in the toolbar was replaced with a generic one on purpose.
- Use the title and caption in manifest.json as alt text and captions.

Program download
- The signed program is in downloads/Netring-GPO-Compliance.zip. Offer it as the main download next to the user guide. Show the version and the SHA-256 from the manifest so visitors can verify it.

How an update works (done in the product project, not by the website)
1. Rebuild the guide, screenshots and samples and overwrite the same file names.
2. Update version, date and SHA-256 values in website/manifest.json.
3. Run tools\Publish-WebAssets.ps1 in the product project. It checks every file against the manifest and replaces main in the public repository with a single new commit. The website pulls the new files and can compare the SHA-256 values to see what changed.
